## Rules that do not move

- The Frame walk claim does **not** transfer to a heavy soft shell.
- 32–38 kg silicone stays poseable / stand-locked. No dressed walk on hobby servos.
- Skin contact cap **41 °C**. Sleeve internal cap **42 °C** hardware fuse, firmware \~40 °C.
- Human-contact interrupt **35 N** on any clamp, pinch, or closing actuator.
- Soft safety skin on any human-proximate surface that has a heater or motor behind it.
- Bus for this hang: **12 V** chassis heaters / compute brick, fused. GFCI on wall supplies.
- Never mains in the pelvis.
- Adult-only if the cover is adult. Operator 18+. Appearance adult.
- Skills / LLM cannot override E-stop, brownout, heater fuse, or the 35 N interrupt.
- Cloud girlfriend is not the servo brain. Local-first. WAN opt-in and off by default.

## Feel-me research (optional, not a SKU)

Parked so the “toy” ideas survive without rewriting `FRAME.md`.

Intent: a human can touch the hang, the hang can log pressure / temperature / a slow “pulse” cue,
and a local stack can change voice or heat set-point. None of this is a walk claim.

1. **Tactile layer** — start with one FSR coupon (`PHASE0.md`). Later a multiplexed grid
   (the old UBHP-1 64-channel piezoresistive note is a target, not a day-one BOM).
   Log newtons. Software halt at **35 N** if a clamp exists.
2. **Heat** — 12 V graphene or silicone pad, NTC on the face, firmware drop at 41 °C,
   hardware fuse ≤ 45 °C. 30 min soak on the card.
3. **Pulse cue** — optional low-force periodic haptic or LED/audio metronome in the chest.
   Not a medical device. Not a heartbeat claim. Keep force under the 35 N cap.
4. **Smart-control** — Jetson / local LLM interprets touch + temp + voice.
   Session machine if you use it: Idle → Preheat → Attend → Intimate → Cleanup (+ Fault).
   Safe-reserve: if pack or thermal headroom dies, heaters and sleeve motors drop; voice may stay.
5. **Intimate cartridge** — removable sleeves only. Wash + dry time on the card.
   Leak-down 30 min. Separate parts. No permanent plumbing on the Frame.

Do not invent closed-loop bedroom walking from this list.
